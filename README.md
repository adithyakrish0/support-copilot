# Support Copilot + QA Scorecard

AI-powered customer support triage engine with an automated evaluation dashboard.

## Key Features
- **Intelligent Triage:** Auto-categorizes tickets and detects escalation triggers.
- **QA Scorecard:** Automated evaluation of LLM responses for grounding and accuracy.
- **Observability:** Integrated with Langfuse for real-time trace monitoring.

## Tech Stack
- **Frontend:** Streamlit
- **AI Backend:** Groq / OpenRouter (OpenAI-compatible)
- **Monitoring:** Langfuse
- **Infrastructure:** Supabase (planned)
